# Knight Survivors

A 3D isometric horde-survival roguelite (think Vampire Survivors): one knight, endless zombies,
automatic attacks, and plenty of blood.

- **Engine:** Unity **6000.3.27f1** (Unity 6.3 LTS), Universal Render Pipeline (URP), PC.
- **Design docs:** `docs/GDD.md` (rules and numbers; v0.3 is frozen), `docs/ArtDirection.md`, `docs/PlaceholderSpec.md`.
- **Git LFS is required.** Install it once (it ships with Git for Windows and GitHub Desktop), then run `git lfs install`
  before cloning. `.gitattributes` already routes textures, models and audio to LFS.

The code foundation (graybox scripts, the one-click scene builder, `docs/TechPlan.md` and full setup steps)
lives on the `feature/tech-foundation` branch and its pull request.
